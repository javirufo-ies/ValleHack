**Reproducible ethical hacking labs for cybersecurity training and education.**

ValleHack delivers reproducible, portable, and easy-to-deploy learning environments that help students acquire practical cybersecurity skills through hands-on exercises and CTF-style challenges.

## Goals

- Provide portable cybersecurity laboratories based on containers.
- Facilitate ethical hacking training without requiring dedicated hardware.
- Support hands-on learning through realistic scenarios and challenges.
- Enable educators to deploy consistent learning environments across different platforms.
- Integrate practical exercises, CTFs, and assessment activities.

## Features

- Containerized learning environments.
- RootTheBox integration.
- Versioned laboratory content.
- Easy deployment scripts.
- Reproducible cybersecurity scenarios.
- Distribution-independent design.
