
# ValleHack Scenarios

**Story-driven cybersecurity learning environments for ValleHack.**

ValleHack Scenarios are self-contained educational campaigns designed to teach cybersecurity through practical activities, realistic infrastructures, and narrative-driven challenges.

Each scenario can be installed independently and provides its own learning environment, challenges, containers, and storyline.

## What is a Scenario?

A scenario is a complete cybersecurity learning experience that may include:

* RootTheBox challenges
* Docker-based target systems
* Learning activities
* Assessment tasks
* Flags and objectives
* Storytelling elements
* Documentation

## Educational Philosophy

ValleHack follows a learning-by-doing approach.

Students develop cybersecurity skills by interacting with realistic systems, investigating incidents, identifying vulnerabilities, exploiting weaknesses in controlled environments, and applying defensive measures.

## Available Scenarios

### Valle del Jerte

A cybersecurity campaign inspired by organizations and services located throughout the Jerte Valley.

Possible environments include:

* Municipal services
* Tourism platforms
* Agricultural cooperatives
* Educational institutions
* Local businesses

### Game of Thrones

A fantasy-themed campaign inspired by the political and technological infrastructure of Westeros.

Possible environments include:

* Winterfell
* King's Landing
* Dragonstone
* Castle Black
* The Wall

### Outlander

A historical-inspired campaign featuring environments based on locations and characters from the Outlander universe.

### Future Scenarios

Additional campaigns may cover:

* Corporate Security
* Healthcare Environments
* Critical Infrastructure
* Industrial Control Systems
* Cloud Security
* Malware Analysis

## Scenario Structure

```text
scenario-name/
├── manifest.yaml
├── rtb/
├── containers/
├── story/
├── docs/
└── assets/
```

## Learning Outcomes

Scenarios may support one or more learning outcomes related to:

* Reconnaissance
* Enumeration
* Vulnerability Analysis
* Exploitation
* Privilege Escalation
* Digital Forensics
* Incident Response
* Hardening
* Secure Deployment

## Creating a New Scenario

Educators can create their own scenario packages by following the structure described in the documentation.

Custom scenarios can be used to adapt learning activities to different educational contexts and student groups.
